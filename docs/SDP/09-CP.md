## 2. RESTART AND VERIFY (standard procedure, W80/W81)
1. Stop the backend (Ctrl+C in the admin console). An ERROR traceback on SIGINT shutdown is expected (W80 N2).
2. Start with `.\start-openjarvis.ps1` from C:\Users\Admin\OpenJarvis (other launch methods lose INFO logging).
3. Confirm by process START time newer than the change; BIND_ASSERT in backend.log shows 127.0.0.1:8010.
4. Round trip: POST /v1/chat/completions stream=true, no agent -> reply in about 0.7 s warm; first call after idle adds ~12 s model reload.
