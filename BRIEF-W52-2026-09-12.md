## HARD FACTS A NEW WINDOW WILL GET WRONG

- **THE test-execute BODY KEY IS `arguments`, NOT `args`.** An object. `{"tool":
  "shell_exec","arguments":{"command":"echo x"}}`. Sending `args` now returns 400 naming
  the unknown field. This exact typo cost W52 three exchanges.
- **`shell_exec` REQUIRED PARAM IS `command`.** Optional: `timeout` (default 30, max
  300), `working_dir`, `env_passthrough`. Read from source, not a register.
- **dispatch.log IS THE INSTRUMENT THAT SETTLES GATE QUESTIONS.**
  `%LOCALAPPDATA%\OpenJarvis\logs\dispatch.log`. Paired ATTEMPT/OUTCOME on every path.
  Check it before building anything new. `reason=OK` means the tool actually ran.
- **APPROVE/DENY LATENCY IN THAT LOG IS HUMAN READING TIME, NOT SYSTEM LATENCY.**
- **`Invoke-RestMethod` CONSUMES THE ERROR STREAM.** The status code is reliable; the
  body often comes back empty from the StreamReader. Do not read an empty body as an
  empty server response.
- **POWERSHELL 5: `$(if ...)` NOT `(if ...)` INSIDE A FORMAT STRING**, and a multi-line
  `if/elseif/else` pasted line-by-line BREAKS. Keep branching on ONE line.
- **`[IO.File]::ReadAllText` USES `C:\WINDOWS\system32` AS ITS WORKING DIRECTORY.**
  Always `Resolve-Path` first. Relative paths silently target the wrong place.
- **UVICORN'S ACCESS LOG DOES NOT RECORD PAGE OR ASSET FETCHES.** `GET /` writes NOTHING
  to backend.log. Do not use it to decide whether the frontend loaded. `ws-accept` does land.
- **THE EXE EMBEDS THE FRONTEND.** Frontend change means full `npm run tauri build` then
  relaunch. **The build EXITS 1 ON SUCCESS** (updater signing, no private key) - check the
  exe timestamp, not the exit code. About 2m 40s. A BACKEND-only change needs only a
  restart via `.\start-openjarvis.ps1`.
- **`confirm_tool` ACCEPTS `approved`/`denied` AS WELL AS `approve`/`deny`.** The W51
  BRIEF said lowercase approve/deny only. The register was narrower than the code.
- **Carried and still true:** ~120 s means nobody answered, not a fault. `data.agent_id`
  on a confirm frame is the executor CLASS identity (`native_openhands`), never an
  instance id - filtering on it is what kept the chat path dark. Redaction fails CLOSED if
  the bind is not loopback. `OPENJARVIS_TEST_EXEC` must be set in the BACKEND'S
