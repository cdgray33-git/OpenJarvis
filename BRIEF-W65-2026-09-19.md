## HARD FACTS A NEW WINDOW WILL GET WRONG
- **"Speakers (USB Audio and HID)" IS NOT A SPEAKER.** Phantom sink on a
  mic dongle. Never set default render to it. Real output is SAMSUNG (HDMI).
- **CHECK HARDWARE PRESENCE BEFORE TRUSTING A CARRIED TEST.** W64's item-1
  test named the Elgato Wave:3; it is UNPLUGGED (status Unknown). The test
  could not run as written.
- **state=0 DOES NOT MEAN BROKEN.** run2 read state=0 on the session that
  measured 0.971459. State is sampled; peak is a max over the run. TRUST
  THE PEAK.
- **A SESSION LISTED UNDER AN ENDPOINT IS NOT PROOF OF ROUTING.** run1 filed
  the webview session under SAMSUNG while it rendered nothing anywhere.
- **CHROMIUM BIND-FOR-LIFE IS UNPROVEN IN BOTH DIRECTIONS.** W64's strong
  form does not fit run1; run2 included a relaunch so it cannot separate
  rebind-on-change from bind-at-creation. Do not assert either. setSinkId
  makes it moot.
- **AN ACTIVE AUDIO SESSION IS NOT AUDIBLE AUDIO.** KEEPALIVE_GAIN = 0.0 on
  its own gain node; speech is on masterGain (gain 1). No gain-zero speech
  path. Only a PEAK reading distinguishes audio from silence.
- **ENDPOINT INVENTORY IS A ONE-LINER, NOT A SCRIPT:** Get-PnpDevice -Class
  AudioEndpoint plus Get-PnpDeviceProperty DEVPKEY_Device_Parent.
- **A DELIVERED .ps1 WILL NOT RUN AS DELIVERED.** `Unblock-File` AND
  `powershell.exe -ExecutionPolicy Bypass -NoProfile -File <ABSOLUTE path>`,
  in the SAME message as the file. PASTING A SCRIPT BODY IS NOT RUNNING IT.
- **TWO api.ts FILES:** `frontend\src\lib\api.ts` (1007 lines) and
  `frontend\src\components\Desktop\lib\api.ts`. Duplicate-code hazard.
- **`start-openjarvis.ps1` STARTS ONLY THE BACKEND** (line 57, uvicorn 8010).
  The desktop app launches separately, from the shortcut.
- **A REBUILD IS NOT AN INSTALL.** `npx tauri build` writes
  `frontend\src-tauri\target\release\`; the shortcut runs
  `%LOCALAPPDATA%\OpenJarvis\`. Reinstall with
  `target\release\bundle\nsis\OpenJarvis_0.1.0_x64-setup.exe /S`.
  ALWAYS SAY WHICH EXE A TEST RAN. Installed exe: `openjarvis-desktop.exe`
  dated 09/17 08:46:32. There is NO `OpenJarvis.exe`.
- **BUILD:** `npx tauri build` from `frontend\`, ~200 s, exits 1 on the

- **`backend.log` IS HELD OPEN.** `[IO.File]::ReadLines` FAILS. Use
