## HARD FACTS A NEW WINDOW WILL GET WRONG
- **DO NOT RE-DERIVE THE STOP WIRING. IT IS DONE AND VERIFIED PRESENT.**
  Seven anchors were counted in place. The defect is elsewhere.
- **`sse.ts` HONORS THE CALLER'S SIGNAL.** `sse.ts:41`
  `const combinedSignal = signal || timeoutController.signal;` - the abort
  DOES reach the fetch. This was the leading theory and it is DEAD.
- **THERE IS NO 30-SECOND TIMEOUT ON CHAT REQUESTS.** When a caller passes
  a signal, `timeoutController` is constructed and never used. The timeout
  applies only to `streamResearch`. Unrelated to today; do not lose it.
- **THE THINKINGCIRCLE OVERLAY THEORY IS DEAD.** `ChatArea.tsx:437` is
  `position: fixed, zIndex: 999998`, which looked damning. Retired without
  a build once the freeze explained the missing hover.
- **`npx tauri build` MUST RUN FROM `frontend`.** There is no root
  `package.json`; the CLI is at `frontend\node_modules\.bin`. From the repo
  root it fails with "could not determine executable to run" - a location
  fault, NOT a build failure, and the W68 retry-once rule does not apply.
- **`npm run build:tauri` IS `tsc -b && vite build` - FRONTEND ONLY.** It
  does not compile the Rust exe despite the name.
- **A BUILD CANNOT OVERWRITE A RUNNING EXE.** Reports as
  `failed to remove file ... Access is denied (os error 5)` then
  `failed to build app`, with no mention of the app being open. Retrying
  unchanged fails identically. Shut both ends down first.
- **THE NSIS INSTALLER IS NOT REQUIRED.** A direct exe copy into
  `%LOCALAPPDATA%\OpenJarvis\` installs the build - non-interactive,
  scriptable, reversible. Four windows used the GUI without needing to.
- **NEVER PASTE CONSOLE OUTPUT BACK INTO POWERSHELL.** A bare file path on
  a line EXECUTES it. Doing so launched the MSI and the NSIS setup this
  window. Nothing was damaged, but it cost real time.
- **ALL W67 AND W68 HARD FACTS REMAIN IN FORCE.** See BRIEF-W68.
