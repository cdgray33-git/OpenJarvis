## HARD FACTS A NEW WINDOW WILL GET WRONG
- **THE RE-KICK GATE MUST NOT TEST GENERATION.** On a generation-change
  return, `myGeneration` is stale BY DEFINITION - that is why the instance
  is returning. Gating the re-kick on a generation match would skip it in
  exactly the case it exists for. `pending.length > 0` alone is correct.
  Termination is safe: every return path sits behind an await or after a
  `shift()`, so `pending` strictly shrinks.
- **ORDER INSIDE THE `finally` MATTERS.** `pumping = false;` must precede
  the re-kick. Reversed, the re-kicked pump bounces off `if (pumping)
  return;` and does nothing. Current order at :297/:298 is correct.
- **THE STOP CONTROL SILENCES BUT DOES NOT STOP.** Gray, W68: "I am unable
  to stop Jarvis... I can silence Jarvis, but not stop Jarvis." `stopAll()`
  runs on the TTS side only; the backend stream keeps producing and
  ChatArea keeps calling `enqueue()`. The only way to end a turn is to send
  another message. This is F-W62-5 and it is now MEASURED, not believed.
- **A `tauri build` CAN FAIL WITH NO DIAGNOSABLE ERROR AND SUCCEED
  UNCHANGED ON RETRY.** W68 hit exit 1 with no artifact written, retried
  the identical tree, and got a good bundle. DO NOT BISECT A PATCH ON A
  SINGLE FAILED BUILD. Retry once first.
- **`npx tauri build` STDERR IS NOT AN ERROR.** PowerShell wraps tauri's
  progress output as `NativeCommandError` and the word "Error" appears in
  the wrapper. Grepping for `error|Error:` returns that noise and hides the
  real failure. Tail the log instead of pattern-matching it.
- **KNOWN EDGE, ACCEPTED:** the `if (!context) return;` path now drains the
  queue by synthesizing each unit before discovering there is no context -
  wasted round-trips bounded by queue length. Cannot fire in practice
  (`enqueue` calls `ensureContext` before pushing). Not a defect to chase.
- **A `Select-String` TIME FILTER MUST ANCHOR THE FULL DATE AND HOUR.**
  `1[1-9]:` matches the MINUTE field of `10:13`. W68 pulled stale baseline
  lines twice this way and nearly called a stale read a pass. Use
  `2026-09-20 1[1-9]:` form. **AN EMPTY RESULT MUST MEAN "NO DATA", NEVER
  "PASS".**
- **THE SAME PROMPT DOES NOT PRODUCE THE SAME REPLY.** `s` yielded 33 chars
  (6+27) at 10:13, 10:23, 10:51 and 177 chars (6+48+27+96) at 10:29. Unit
  counts vary by REPLY, not by patch. Compare BYTE COUNTS to identify a
  matching turn before calling anything a regression.
