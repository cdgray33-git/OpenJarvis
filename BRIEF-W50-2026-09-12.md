## HARD FACTS A NEW WINDOW WILL GET WRONG

- **`websockets` IS 17.0.1 AND THE LEGACY ASYNCIO CLIENT IS GONE.** python 3.12.10.
  `websockets.connect(...)` in the asyncio style HANGS in the opening handshake against
  a healthy server. Use `from websockets.sync.client import connect`, then
  `connect(url, open_timeout=15)` and `conn.recv(timeout=...)` which raises
  `TimeoutError`. Proven 56 ms. **`probe_ws_bare_subscribe.py` is DEAD for this reason
  and has been silently unusable since the upgrade.**
- **A HUNG WS HANDSHAKE IS NOT EVIDENCE THE SERVER IS BROKEN.** Discriminate with a
  .NET `ClientWebSocket` first - it costs 92 ms.
- **SETTING `requires_confirmation=True` ON A TOOL WITH NO BROWSER LISTENER MEANS EVERY
  CALL PARKS 120 s THEN FAILS**, and the agent RE-REQUESTS after a TIMEOUT ToolResult,
  so the cost is N x 120 s on the shared ThreadPoolExecutor, not 120 s once. Action 4
  is cheap only after action 1.
- **`test-execute` RETURNS 202 WITH `turn_id` = `"test-" + run_id`** (`:2233`). Guards
  in order: 403 flag unset (`:2157`), 403 bind not loopback (`:2167`), 409 no live
  executor (`:2179`), 400 no tool (`:2200`), 404 unknown tool WITH a live inventory
  (`:2213`), 422 tool does not require confirmation (`:2223`). A bogus-tool POST
  clears all four guards in ONE call - use it as the cheap liveness check.
- **`POST /v1/tools/confirm` CALLS `_cr.get()` BEFORE `resolve()`** (`:2085`), so an
  expired id gives 404 and never a false 200. Accepts approve/approved/deny/denied.
